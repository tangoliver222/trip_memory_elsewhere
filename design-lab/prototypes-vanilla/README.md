# Elsewhere canonical vanilla application

This directory is the only production Elsewhere application. The root React/Vite project is a preview workbench and `design-lab/elsewhere-frontend-v1` is archived reference code.

## Commands

```bash
npm install
npm run dev
npm test
npm run build
npm run test:e2e
```

The dev server defaults to `http://127.0.0.1:4174`.
