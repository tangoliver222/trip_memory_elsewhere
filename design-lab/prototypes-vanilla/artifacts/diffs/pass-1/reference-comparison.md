# Pass 1 · 参考图人工差异记录

像素差不适用于不同内容、比例与字体的概念参考图；本文件记录语义视觉差异，并由 Playwright 截图作为证据。

| 参考 | 对应实现 | Pass 1 处理 |
|---|---|---|
| Importing | Processing / Import Receipt | 保留黑底、细粒子凝聚和单状态中心；进度只显示 fixture 中可支持的阶段 |
| Settings / Fragment Lens | Me / Lens | 工具页降噪；Lens 保留原空间、从节点提取后转为可读面板 |
| City / Field / Timeline / Places | 同名核心页 | 统一银白点云骨架、真实原件、多 Z 深度和不同视角结构 |
| Discovery | Discovery Detail | 三日期原件先出现，关系流随后成立，共同地点凝聚后标题显影 |
